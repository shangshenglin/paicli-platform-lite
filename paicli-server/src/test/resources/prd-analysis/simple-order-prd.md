# 订单退款 PRD（Simple Order）

## 1. 概述
本系统提供订单创建与退款申请能力。用户下单后生成订单，支付完成后可在 7 天内申请退款，退款需经过审核。

## 2. 订单创建
- 用户提交商品、数量与收货信息后创建订单。
- 订单字段：orderId、userId、amount、status、createdAt。
- 订单初始状态为 CREATED。
- 订单金额必须大于 0。

## 3. 支付
- 支付成功后订单状态变为 PAID。
- 只有 PAID 状态的订单可以申请退款。

## 4. 退款申请
- PAID 订单可在支付完成后 7 天内申请退款。
- 退款申请字段：refundId、orderId、reason、amount、status、createdAt。
- 退款金额不能超过订单实付金额。
- 退款状态流转：APPLIED → APPROVED → REFUNDED。
- 审核拒绝时状态变为 REJECTED。

## 5. 业务规则
- 同一订单只能申请一次退款。
- 退款金额不能超过订单金额。
- 超过 7 天窗口的订单不允许申请退款。
- 审核人不能审核自己提交的退款。
